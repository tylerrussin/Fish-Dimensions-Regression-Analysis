### E1 (log target) — проверка логарифмирования целевой переменной

**Гипотеза**: при сильной асимметрии целевой переменной (что мы видели на распределении Weight) логарифмирование `log(1+y)` должно улучшить линейную модель.

**Результат**: Test MAE = **127.85**, Test R² = **0.1123**. 

**Вывод**: логарифмирование целевой переменной **ухудшило** результат по сравнению с обычной E1 (MAE = 58.27). 
*Причина*: линейная регрессия на сырых признаках (`Length1`, `Length2`...) предполагает аддитивную связь. Логарифмирование цели делает связь мультипликативной, но признаки остаются в исходном масштабе, что создаёт сильное смещение при обратном преобразовании `expm1`. Чтобы логарифмирование сработало, нужно также логарифмировать признаки (например, использовать `log(V_approx)`).

**Лучшая модель**: E4 (Ridge + V_approx) — Test MAE 36.54, R² 0.986.
